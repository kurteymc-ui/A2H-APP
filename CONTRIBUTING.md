# Contributing

A2HMeter is made by AION 2 Helper and is not open source (see [LICENSE](LICENSE)), so it does not take code or pull requests.
Everything else helps a lot:

- **Report a bug**: use the bug report form. A debug recording or the network log makes most problems much easier to solve.
- **Suggest something**: open a feature request and say what you were trying to do.
- **Wrong texts or game names in your language**: open an issue and say what the game shows. Names come from the AION 2
  client of that language, never from wikis.

Never include recordings, logs or screenshots with real player names or account data.
